Q154 答案錯誤

靜態路由的設定階層

When configuring static routes, which command is typically used?

題庫答案 A. set protocols static route
正解 set routing-options static route —— 不在四個選項內

Junos 沒有 [edit protocols static] 這個階層。靜態路由屬於 protocol-independent routing，設定在 [edit routing-options] 之下；若在 routing instance 內，則是 [edit routing-instances <name> routing-options]。

user@router# set protocols static route 10.0.0.0/8 next-hop 192.168.1.1
                    ^
syntax error.

user@router# set routing-options static route 10.0.0.0/8 next-hop 192.168.1.1
user@router# set routing-options static route 10.0.0.0/8 qualified-next-hop 192.168.1.2 preference 7
注意 同一份題庫的 Q169（「靜態路由設在哪個階層？」答 routing-options）是正確的 —— 兩題直接打架。以 Q169 為準。
Q105 Cisco 語法

查看 OSPF 鄰居的指令

In OSPF, which command is commonly used to monitor neighbor relationships?

題庫答案 A. show ip ospf neighbors
正解 show ospf neighbor —— 不在四個選項內

show ip ospf neighbors 是 Cisco IOS 的寫法。Junos 的操作模式指令沒有 ip 這一層，而且用單數 neighbor。

另外兩個選項雖然是合法的 Junos 指令，但查的不是鄰居狀態：

  • show ospf database —— 看 LSDB 裡的 LSA
  • show ospf interface —— 看介面的 area、DR/BDR、鄰居數（題目誤寫成 interfaces）
user@router> show ospf neighbor
Address          Interface       State     ID              Pri  Dead
10.1.1.2         ge-0/0/0.0      Full      10.255.0.2      128    36
10.1.2.2         ge-0/0/1.0      Full      10.255.0.3      128    33
Q167 對 Juniper 不成立

IBGP 與 EBGP 的主要差異

What is the primary difference between IBGP and EBGP?

題庫答案 B. The administrative distance
正解 A. The way they advertise routes（路由通告方式）

Junos 中 IBGP 與 EBGP 的 route preference 都是 170，根本沒有差別，所以「administrative distance 不同」在 Juniper 上不成立。eBGP 20 / iBGP 200 那是 Cisco 的行為。

真正的核心差異是通告規則：從 IBGP peer 學到的路由，預設不會再通告給其他 IBGP peer（這正是需要 full mesh 或 route reflector 的原因）；EBGP 則沒有這個限制。

user@router> show route protocol bgp detail | match preference
  # EBGP 學到的路由
                Local preference: 100, Peer AS: 65201
                Preference: 170
  # IBGP 學到的路由 —— 同樣是 170
                Local preference: 100, Peer AS: 65101
                Preference: 170
對照 同題庫 Q197（「從 IBGP peer 收到的路由預設不會通告給另一個 IBGP peer」答 A. IBGP, IBGP）講的就是這條規則，而且答對了。

Which LSA types are associated with OSPF? (Choose three)

Q178 答案可爭議

影響 BGP 選路的屬性

Fill in the blank: In BGP, the _____ attribute is used to influence the best path selection process.

題庫答案 A. MED
更合理 C. Local Preference

AS_PATH、Local Preference、Community 四個選項全都會影響選路，題目沒有限定條件。若要選「最主要」的，Local Preference 更站得住腳：它在選路順序中排在 AS path 之前，是 AS 內部控制出向流量的主要工具；MED 只用來建議鄰居 AS 該從哪個入口進來，影響範圍小得多。

Q64 非預設行為

MAC limiting 違規時的預設動作

When a MAC limiting violation occurs, the switch performs which two actions by default? (Choose two.)

題庫答案 C. The port is disabled + D. It drops the packet
實情 只有 D（drop）是預設；關閉介面必須明確設定

Junos interface-mac-limit 的預設 packet-action 是 drop —— 超過上限的來源 MAC 其封包被丟棄，但介面保持 up。要讓介面被關掉，得自己指定 shutdown。

# 預設：超限就丟包，介面不動
user@switch# set switch-options interface ge-0/0/1 interface-mac-limit 5

# 要關介面必須明講
user@switch# set switch-options interface ge-0/0/1 interface-mac-limit 5 packet-action shutdown

題庫的解說寫「port is automatically disabled」是把可設定的 shutdown 動作當成了預設。這是「選兩個」硬湊出來的第二個答案。

Q68 觀念錯誤

VLAN 減少了什麼

VLANs help in reducing which of the following? (Choose two)

題庫答案 A. Collision domains + B. Broadcast domains
實情 兩個都站不住腳，只是「最不爛」的選項
  • 碰撞網域與 VLAN 無關 —— 那是交換器本身解決的（每個 port 自成一個碰撞網域，見同題庫 Q10 與 Q128）。把所有 port 放進同一個 VLAN，碰撞網域數量也不會變。
  • 廣播網域被 VLAN 切開後是變多、變小，不是「減少」。一台交換器切 4 個 VLAN，就從 1 個廣播網域變成 4 個。

精準的說法是：VLAN 縮小每個廣播網域的範圍（size），而非減少其數量。選項 C（Routing complexity，VLAN 反而增加）與 D（Encryption requirements，無關）更離譜，所以 A、B 只是矮子裡拔將軍。

Q93 ⇄ Q136 互斥

OSPF Router ID 怎麼選出來

Q93 答 A, B —— 其中 B：預設取任一 active interface 的最高 IP
Q136 答 D：取最高的 loopback 介面 IP
Junos 實情 手動設定 > lo0 的位址 > 第一個有位址的介面

兩題答案互斥，而且都不完全對。Junos 的挑選順序是：

  • 1. routing-options router-id 明確指定（最優先，IP fabric 一定這樣做）
  • 2. lo0 上設定的 IP 位址
  • 3. 第一個有位址的介面

「取最高 IP」是 Cisco 的規則，Junos 不是這樣挑的。Q93 的選項 A（可手動設定）本身正確。

user@router# set routing-options router-id 10.255.0.1

user@router> show ospf overview | match "Router ID"
  Router ID: 10.255.0.1
Q6 ⇄ Q7 說法分歧

OSPF 在哪個狀態檢查 MTU

Q6「哪個狀態檢查 MTU？」→ Exchange
Q7「卡在 ExStart 的原因？」→ MTU mismatch

兩題答案都可以接受，但並存容易讓人混淆。原因是 MTU 欄位放在 DBD 封包的標頭裡，而 DBD 從 ExStart（主從協商）就開始交換，到 Exchange 才真正帶 LSA 摘要。實務上 MTU 不符會讓鄰居在 ExStart / Exchange 之間反覆跳動。

記法 問「在哪個 state 檢查 MTU」→ 選 Exchange；問「卡在 ExStart 的原因」→ 選 MTU mismatch。兩題各答各的，不要互相套用。
user@router> show ospf neighbor
Address          Interface       State      ID            Pri  Dead
10.1.1.2         ge-0/0/0.0      ExStart    10.255.0.2    128    38

# 兩端 MTU 對不起來
user@router> show interfaces ge-0/0/0 | match MTU
  Link-level type: Ethernet, MTU: 1514
user@peer>   show interfaces ge-0/0/0 | match MTU
  Link-level type: Ethernet, MTU: 9192
Q63 ⇄ Q90 單選題兩個對

VLAN 排錯該用哪個指令

Q63「顯示 VLAN ID 與 port 對應」→ show vlans ✓ 正確
Q90「排查 VLAN 問題」→ show ethernet-switching table ⚠ 可爭議

Q90 是單選題，但 show vlans 同樣是有效答案，而題目完全沒界定要查什麼。兩個指令查的是不同層面：

  • show vlans —— VLAN 有哪些成員 port、tag 模式（設定面）
  • show ethernet-switching table —— 每個 VLAN 學到哪些 MAC、從哪個 port 進來（轉送面）
考場策略 看到「VLAN 與 port 的對應／成員關係」選 show vlans；看到「MAC 學習、通不通」選 show ethernet-switching table。

Q74 Cisco 語法

定義 BGP neighbor 的指令

When configuring BGP, which command is commonly used to define a BGP neighbor?

題庫答案 B. neighbor <IP> remote-as <AS>
Junos 寫法 set protocols bgp group <name> neighbor <IP> peer-as <AS>

題庫答案是 Cisco IOS 語法。Junos 用 peer-as 而非 remote-as，而且 neighbor 一定掛在 group 底下。四個選項裡沒有 Junos 的正確寫法。

user@router# set protocols bgp group underlay type external
user@router# set protocols bgp group underlay local-as 65101
user@router# set protocols bgp group underlay neighbor 172.16.1.1 peer-as 65201
Q163 超出考綱

BGP Weight 屬性

What is the function of the 'Weight' attribute in BGP, and where is it used in the route selection process?

題庫答案 C. Cisco 專屬屬性，在 Local Preference 之前評估 —— 敘述本身正確
但是 Junos 完全沒有 Weight 這個概念

Weight 是 Cisco 的私有屬性，只在本機有效、不隨 update 傳遞。Junos 沒有對應的東西；要達到類似「只影響本機選路」的效果，Juniper 的做法是調 route preference 或用 policy 設 local-preference。

這題答對了也學不到 Junos 的知識，出現在 JNCIA-DC 題庫裡本身就是個訊號 —— 這份題庫混了別家廠商的題目，Q74、Q105、Q167、Q93 都是同樣來源。
